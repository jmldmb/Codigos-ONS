# Testes

Scripts de teste do sistema.

## Arquivos

### `teste_modelo_completo.py`
Teste completo do modelo com poucos cenários.

**Funcionalidades:**
- Teste rápido (5-10 simulações)
- Valida samplers calibrados (eólica, solar, carga)
- Verifica funcionamento end-to-end

**Uso:**
```bash
python src/testes/teste_modelo_completo.py
```

**Configuração:**
- Meses: Janeiro e Julho de 2024
- Cenários: 5-10
- Duração: ~2-5 minutos

**Ideal para:**
- Testes rápidos após mudanças
- Verificar se tudo funciona
- Antes de simulações grandes
